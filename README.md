# EchoGPT

A modern, minimal Next.js & Tailwind CSS AI chat application built with mock chatting data. This is a frontend project assignment for the **Software Engineering Internship (Frontend) — Onsite position at AppifyDevs**.

## Features

* **Interactive AI Mascot:** Sleek custom logo with ambient glow and hover effects.
* **Responsive Sidebar:** Smooth collapsing, mobile overlay, and clean navigation.
* **Mock Chatting Data:** Fully structured frontend layout ready for interactive chat workflows.
* **Modern Design:** Minimalistic, comment-free components using Lucide icons.

## Quick Start

```bash
npm install
npm run dev

```

Open [http://localhost:3000] to view it.
